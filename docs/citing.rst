************
How to cite?
************

If you use this software in a scientific publication, please cite it as follows:

    PACSIFIER: batch DICOM query/retrieve tool for PACS systems.
    Translational Machine Learning Lab, Lausanne University Hospital and University of Lausanne.
    https://github.com/TranslationalML/pacsifier

.. note::
    A Zenodo DOI will be provided in a future release. Please check the
    `GitHub repository <https://github.com/TranslationalML/pacsifier>`_ for updates.
